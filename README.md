# Mike Interiors

A responsive Next.js website rebuild for Mike Interiors, Abraka, Delta State, Nigeria.

## Stack
- Next.js App Router
- React + TypeScript
- Tailwind CSS v4 (with a custom editorial design system)
- Framer Motion
- Lucide icons

## Local development
```bash
npm install
npm run dev
```

## Production
```bash
npm run build
npm start
```

## Deployment
Configured for a standard Next.js deployment on Netlify. Connect this repository to Netlify and use the Next.js runtime/plugin. No environment variables are required for the current frontend.

## Important content notes
- Existing Mike Interiors brand name, location, phone number and one verified project image are retained.
- Editorial interior photography on the homepage and Design Ideas page is inspiration imagery, not represented as client work.
- The portfolio deliberately avoids invented projects or testimonials. Add recovered project assets and captions when verified.
- The enquiry form prepares an email on the visitor's device; it does not claim server-side delivery. Connect a transactional email provider before implementing server submission.
